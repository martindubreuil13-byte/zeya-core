# Conversation Manual

How to design and run conversations that enable representation. Frameworks for dialogue-based discovery and validation.

**Status:** Placeholder Architecture

## Purpose

Representation happens through conversation, not through monologue.

This manual answers: "How do I run a conversation that builds representation?"
